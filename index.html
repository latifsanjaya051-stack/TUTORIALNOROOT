TIPS KEAMANAN NON-ROOT

Untuk menjaga keamanan akun dan meminimalkan jejak penggunaan plugin, disarankan melakukan Repair Environment secara rutin guna membersihkan sisa cache (*environment footprint*).

Waktu Rekomendasi Repair Environment

Lakukan minimal 1 kali sehari, atau pada kondisi berikut:

  • Setelah mengunduh pembaruan *patch* kecil di layar masuk (*login screen*).
  • Setelah sesi permainan intensif atau penggunaan fitur plugin berlebih (disarankan tetap bermain secara natural).
  • Jika akun mengalami penangguhan (*banned*), wajib melakukan Repair Environment sebelum login dengan akun baru.
Cara Melakukan Repair Environment
  • Tahan ikon game pada aplikasi container Game Assistant.
  • Pilih opsi menu "Repair Environment".
Efek Samping Normal

Setelah melakukan Repair Environment, pembukaan game pertama kali umumnya akan mengalami crash (keluar sendiri). Hal ini adalah normal karena sistem sedang membangun ulang direktori lingkungan kerja. Buka kembali aplikasi game dan semua akan berjalan normal.

Selalu gunakan plugin secara bijak dan utamakan keamanan akun utama
